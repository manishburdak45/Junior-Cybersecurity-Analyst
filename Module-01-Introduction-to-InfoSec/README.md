# Module 01: Introduction to Information Security

##  Overview
This module covers the fundamentals of Information Security (InfoSec), including core principles, roles, and real-world security concepts.

---

##  Key Concepts

###  CIA Triad
- Confidentiality → Only authorized users can access data  
- Integrity → Data should not be modified without permission  
- Availability → Data should be accessible when needed  

---

###  Structure of InfoSec
Based on three main components:
- People → Employees, awareness, human behavior  
- Process → Policies, procedures, incident response  
- Technology → Firewalls, IDS/IPS, encryption  

 Strong security = combination of all three

---

###  Roles in Cybersecurity
- CISO → Overall security strategy  
- Security Analyst → Monitor & analyze threats  
- Penetration Tester → Find vulnerabilities  
- Incident Responder → Handle attacks  

---

###  Network Security Basics
- Firewalls → Filter traffic  
- IDS/IPS → Detect & prevent attacks  
- VPN → Secure communication  

---

###  Application Security
- Secure coding practices  
- Prevent vulnerabilities (SQLi, XSS)  
- Testing + monitoring + updates  

---

###  Cloud Security
- Shared responsibility model  
- IAM (Access control)  
- Encryption & compliance  

---

###  Common Threats
- DDoS Attack  
- Ransomware  
- Social Engineering  
- Insider Threats  
- APTs (Advanced Persistent Threats)  

---

##  What I Learned
- Security is not just tools, it's also about people and processes  
- Human error is one of the biggest risks  
- Security must be implemented from the beginning (Security by Design)
