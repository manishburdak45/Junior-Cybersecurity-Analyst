# 🌐 Networking Overview for Cybersecurity

A professional beginner-to-intermediate networking module designed for cybersecurity learners.

This project contains a dark-themed visual learning presentation focused on networking fundamentals, practical cybersecurity concepts, and real-world networking architecture.

---

# 📚 Topics Covered

## Core Networking Fundamentals
- What is Networking
- Network Topologies
- TCP/IP Basics
- Ports & Services
- TCP vs UDP
- IP Addressing
- MAC Addressing
- Default Gateway
- DNS
- DHCP
- Subnetting

---

## Security & Enterprise Networking
- Flat Network vs Segmented Network
- VLANs
- Firewalls
- ACLs
- Network Segmentation
- IDS/IPS Concepts
- Traffic Monitoring
- Broadcast Domains
- Secure Network Design

---

## Cybersecurity Concepts
- Pivoting
- Lateral Movement
- Packet Analysis
- Attack Surface Reduction
- Network Monitoring
- Secure Communication
- Traffic Filtering
