##  Module 01: Introduction to Information Security

###  Overview

This module covers the foundation of cybersecurity and how information is protected using a combination of **people, processes, and technology**.

---

###  Key Concepts

####  CIA Triad

* **Confidentiality** → Protect data from unauthorized access
* **Integrity** → Ensure data is accurate and not altered
* **Availability** → Ensure data is accessible when needed

---

#### Structure of Information Security

* **People** → Awareness, training, human behavior
* **Process** → Policies, procedures, incident response
* **Technology** → Firewalls, IDS/IPS, encryption

 Strong security depends on all three working together

---

####  Cybersecurity Roles

* CISO
* Security Analyst
* Penetration Tester
* Incident Responder

---

####  Security Domains Covered

* Network Security
* Application Security
* Cloud Security
* Operational Security (OpSec)

---

####  Common Threats

* DDoS Attacks
* Ransomware
* Social Engineering
* Insider Threats
* Advanced Persistent Threats (APTs)

---

##  What I Learned

* Security is not just tools, it also involves people and processes
* Human error is one of the biggest cybersecurity risks
* Security must be implemented from the beginning (Security by Design)

## Module 02: Network Foundations (Completed)

This module helped me build a strong understanding of how networks work and how security applies at different layers.

---

### Part 1: Networking Basics

* What is a network and how devices communicate
* Types of networks (LAN, WAN)
* OSI Model (7 layers)
* TCP/IP Model (4 layers)
* Common protocols (HTTP, FTP, DNS, TCP, UDP)

---

### Part 2: DHCP & NAT

* Automatic IP assignment using DHCP
* DORA process (Discover, Offer, Request, Acknowledge)
* IP leasing and renewal
* NAT for translating private IPs to public IP
* Types of NAT (Static, Dynamic, PAT)

---

### Part 3: DNS & Internet Architecture

* DNS resolution process
* Domain hierarchy (Root, TLD, Subdomain)
* Client-server vs Peer-to-Peer
* Cloud architecture and SDN

---

### Part 4: Network Security & Wireless

* CIA Triad in network security
* Firewalls and filtering techniques
* IDS vs IPS
* Wireless networks and risks
* Security best practices

---

### Final Part: Practical Networking

* Working with network interfaces (ens3, lo, tun0)
* Using tools: ping, netstat, nmap, netcat
* VPN and remote lab access
* Understanding real data flow
